# Code rules

A JSDoc or docblock states behavior: what the function does, its inputs and outputs, how it is used. A README states the package: what it is for, where its spec lives, how to run it, and the setup the machine needs that the code cannot carry. Every other comment states only why the straightforward alternative was not taken, or the constraint that binds the code. Delete a comment or README passage that restates the implementation, also in files you did not write.

Change a generated file by changing its source and regenerating it.
