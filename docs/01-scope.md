# 01. スコープ

## 一文で

原作者がコマ枠、フキダシ、セリフ、指示メモでネームを切り、AI がコマの絵を生成し、アプリが合成して漫画家と編集者に渡すネーム画像を出力するアプリ。

## ユーザーと成果物

- **ユーザーは原作者。** 脚本と演出意図は持っているが、絵は描かない。
- **成果物はネーム画像。** 1 ページ 1 枚の PNG と、エピソード単位の PDF。コマ枠、コマの絵、フキダシ、セリフが合成されている。指示メモは余白に印字するか別紙にする。
- **渡す相手は漫画家と編集者。** 漫画家はこの画像を元に作画する。編集者はこの画像に赤を入れる。
- 画像は「ネーム」であって原稿ではない。構図、芝居、セリフの位置が伝われば足りる。

## 作るもの

### ページとコマ
- コマ割りの作成と調整。矩形ベース。テンプレート（2 段、3 段、4 段、見開き）から開始し、分割と結合で変形する。
- 読み順の自動付番と手動入れ替え。右綴じ縦書き（右から左、上から下）が既定。左綴じにも切り替え可能。
- ページの追加、削除、並べ替え。ページのサムネイル一覧。

### コマの中身（AI への入力）
- フキダシとセリフ。コマ内の位置と大きさ、話者、本文、形（normal / shout / thought / narration）、順番。
- コマごとの指示メモ。演出意図、芝居、時間経過などの自由記述。カメラ（ロング、アオリ、俯瞰など）は独立した項目。
- キャラクター。名前、略称、外見の記述、参照画像。生成でキャラを揃えるために使う。
- 補助: 焦点（FocusPoint。face / keyObject / sfx）と誘導線（Vector。gaze / motion / speed）。構図のヒントとして生成プロンプトに渡す。置かなくても生成はできる。

### 生成（AI の役割）
- コマ単位で絵を生成する。入力はそのコマの指示メモ、カメラ、登場キャラの外見、セリフの話者、焦点と誘導線、プロジェクト共通のスタイル指定、コマ枠とフキダシ領域を示す配置図。
- フキダシ領域は配置図で白抜きにし、絵の主題がフキダシの下に来ないよう促す。
- 修正指示を添えた再生成。前回の絵を参照して差分を出す。
- 生成履歴をコマごとに残し、どれを採用するか切り替えられる。
- ページ単位、エピソード単位の一括生成。
- 参考画像の添付。原作者が持っているラフや資料写真をコマの参照画像として渡す。
- 文字は生成させない。セリフはアプリが描く。

### 合成（アプリの役割）
- 決定論的なレンダラ。同じデータからは同じ画像が出る。
- コマ枠（黒線、コマ番号は任意）、コマの絵（枠でクリップ、cover で配置）、フキダシ（形ごとの輪郭、しっぽ）、セリフ（縦書き、フォント同梱）、指示メモ（任意。余白か別紙）。
- 絵が未生成のコマは白地にコマ番号と指示メモを印字する。生成前でもネームとして成立する。
- 出力解像度は仕上がりサイズと DPI から決める。既定 300dpi。

### 出力
- ページ PNG。1 ページ 1 枚。
- エピソード PDF。ページ順、見開き対応。漫画家と編集者に渡す主成果物。
- JSON。他ツールや LLM との受け渡し用。`03-data-model.md` の形式そのもの。

### 補助: 視線誘導診断
- 各コマの視線経路（centre sweep）と、各焦点とフキダシの t 値（コマ内の位置。0 が入り、1 が出口）。
- 診断結果は生成プロンプトのヒント（「視線は右上のフキダシから左下の顔へ」など）に変換する。
- 評価の表示（診断オーバーレイ、読み順の整合と miss の集計、診断の問題、LLM による修正提案）は止めている。経緯は `06-open-questions.md` の 2026-10-17 の決定。

### 補助: 脚本からの下書き
- 脚本テキストから、ページ分割、コマ割り、フキダシとセリフ、指示メモの初期配置を LLM に提案させる。承認したページだけ追加する。

### プラットフォーム
- Web アプリ（ブラウザ、iPad の Safari 含む）。これが主。
- Desktop アプリ（Tauri 2、macOS と Windows）。
- 同一の React コードベース。差分はストレージと認証のアダプタのみ。

### アクセシビリティ
- コントロールの名前、キーボード操作、フォーカスの見た目、文字と背景のコントラストは守る。
- 読み上げでの操作と見出しの構造は対象外。経緯は `06-open-questions.md` の 2026-10-17 の決定。

## 作らないもの

- 清書、ペン入れ、トーン、仕上げ。作画機能一切。
- 筆圧、傾き、低レイテンシ描画。
- 画像生成モデルの自前ホスト。外部 API を使う。
- 生成画像の手動レタッチ。気に入らなければ指示を変えて再生成する。
- 文字の画像生成。セリフは常にアプリが描く。
- 手描きストロークからの焦点自動抽出（画像認識）。
- PSD の書き出し。レイヤー付き形式の出力。
- モバイルスマホ向け UI。タブレット横向きまでを対象とする。

## 利用場面

- 原作者が脚本を元にコマを切り、セリフと指示メモを入れ、ページを一括生成して PDF を漫画家に送る。
- 漫画家から「このコマは意図が分からない」と言われ、指示メモを直して該当コマだけ再生成する。
- 編集者が PDF に赤を入れ、原作者がセリフと構図を直して再出力する。
- 脚本だけある段階で、LLM に配置の叩き台を出させ、そこから切り始める。
- 構図に迷ったとき、焦点と誘導線を置いて生成に反映する。
