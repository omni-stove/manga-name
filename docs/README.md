# 漫画ネーム生成アプリ 設計ドキュメント

作成日: 2026-10-15

原作者がネーム（コマ枠、フキダシ、セリフ、指示メモ）を構造化データとして作り、AI がコマごとの絵を生成し、アプリがコマ枠とフキダシとセリフを合成してネーム画像を出力するアプリの設計書。
出力は漫画家と編集者に渡す。清書や作画機能は持たない。筆圧検知や描画品質は要件外。
